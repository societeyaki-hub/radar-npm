Politique de confidentialité

Radar npm ne demande aucun compte, ne collecte aucun formulaire et n'enregistre aucune donnée personnelle des visiteurs sur ses propres serveurs.

Le site est hébergé par GitHub Pages, qui peut collecter les données techniques habituelles des serveurs web (adresse IP, navigateur) selon sa propre politique de confidentialité.

Si des publicités ou des outils de mesure d'audience sont ajoutés à l'avenir, cette page sera mise à jour avant leur activation.

Pour toute question, utilise la page de contact.

Cet annuaire est gratuit et mis à jour automatiquement chaque jour à partir du registre npm public. Les chiffres sont les téléchargements hebdomadaires tels que renvoyés par le registre npm.
